### Weather App
# 🌈☀️ Weather App – Summary

### 🌦️ Weather Information

* Provides **current and upcoming weather information**.
* Shows weather details in a **colourful and attractive interface**.
* Helps users understand weather conditions quickly.

###  🏠 Home Page

* Displays the **current weather** of the selected location.
* Shows **temperature, precipitation, humidity, and wind speed**.
* Gives a quick view of the upcoming weather forecast.

###  📍 Location Weather

* Displays weather information for a selected location.
* Example: **Thoothukudi** with its current temperature and weather condition.

###  🔍 City Search

* Allows users to **search for different cities**.
* Displays the weather conditions and temperatures of searched cities.
* Examples include **Mumbai, Chennai, Coimbatore, and Kanyakumari**.

###  📅 7-Day Forecast

* Provides a **7-day weather forecast**.
* Shows the expected **temperature and weather condition** for each day.
* Uses weather icons for easy understanding. ☀️🌤️☁️🌧️

###  🌧️ Weather Conditions

* Represents different conditions using attractive icons.
* ☀️ **Sunny**
* ☁️ **Cloudy**
* 🌧️ **Rain**
* 🌪️ **Storm**
* ⛈️ **Thunder**

###  💧 Weather Details

* Displays important weather information such as:

  * 💧 **Humidity – 61%**
  * 🌬️ **Wind – 8 kph**
  * ☔ **Precipitation – 10%**
* Uses colourful icons and simple labels.

###  💬 Feedback Page

* Allows users to **give feedback** about weather conditions.
* Users can select:

  * ☀️ Sunny
  * 🌧️ Rain
  * 🌪️ Storm
  * ⛈️ Thunder
* A **Submit** option is provided to send feedback.

* Uses a **purple, pink, and blue colour theme**.
* Includes gradient backgrounds and attractive weather illustrations.
* Creates a **modern and visually appealing** look. 🌸💜✨

###  📱 User-Friendly Interface

* Provides simple navigation icons for:

  * 🏠 **Home**
  * 🔍 **Search**
  * 👤 **Profile/Feedback**
* Makes it easy for users to move between different sections.
